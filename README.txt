商户收款码展示站
================

这是什么
--------
一个纯静态的商户收款码展示站，无需后端、无需数据库。
首页列出所有商户（按创建时间从新到旧排序），点击任一商户进入展示页，
展示页只显示收款码图片并可下载。

目录结构
--------
index.html    首页：商户收款码列表
show.html     展示页：单个商户的收款码与下载按钮
data.json     数据文件：所有商户信息
img/          图片目录：存放各商户收款码图片
serve.py      本地预览服务（仅 Python 3 标准库，不用装东西）
启动预览.sh    双击/命令行启动上面的服务

如何新增一个商户
----------------
1. 把收款码图片放进 img/ 目录，例如 img/zhangsan-wechat.png
2. 编辑 data.json，在 merchants 数组里加一条：

   {
     "id": "zhangsan-wechat",
     "name": "张三水果店",
     "createdAt": "2026-11-10 14:30",
     "platform": "微信",
     "image": "img/zhangsan-wechat.png"
   }

字段说明
--------
id          唯一标识，只能用英文、数字与短横线，不要重复（用于页面跳转）
name        商户名，列表和展示页都显示这个
createdAt   创建时间，建议格式 "YYYY-MM-DD HH:mm"，列表按它从新到旧排序
platform    收款平台，填 "微信" 或 "支付宝"（其它值会显示成灰色「未标注」样式）
image       图片路径，相对本站根目录，例如 "img/xxx.png"

注意 data.json 是严格 JSON：逗号、引号不能写错，最后一条后面不要多逗号。

分享给客户
----------
首页每个商户右侧有「分享」按钮，点一下会把该商户的展示链接复制到剪贴板，形如：

    http://你的域名/show.html?id=zhangsan-wechat

把这条链接发给客户，打开直接就是该商户的收款码页，不用再从列表里找。

- 链接里的 id 就是 data.json 里那条记录的 id，改了 id 等于换了链接，旧链接会失效；
- 复制被浏览器拦下时会弹出一个链接面板，长按框里的地址手动复制即可；
- 复制的是「当前访问地址」开头的链接：用 127.0.0.1 打开时复制的是本机地址，
  发给别人打不开，分享前请用正式域名（或局域网 IP）访问。

显示模式
--------
右上角按钮每点一次循环切换：跟随系统 → 白天模式 → 黑夜模式。
选择会记在浏览器本地，下次打开保持。选「跟随系统」时随设备深浅色设置自动变化。
收款码图片所在区域始终是白色底，深色模式下也能正常扫码。

本地预览
--------
页面用 fetch 读取 data.json，直接双击 HTML（file:// 协议）会被浏览器拦掉，
必须经 http 访问。在站点目录里运行：

    sh 启动预览.sh          （Windows 上：python serve.py）

脚本会打印两个地址：本机用 127.0.0.1:8000，同局域网的其他设备（电脑、平板）
用打印出来的那个 192.168.x.x 地址。端口被占用时会自动往后找。按 Ctrl+C 停止。

部署上线
--------
把整个文件夹上传到任意静态托管（GitHub Pages、Cloudflare Pages、Nginx 等）即可。
serve.py 和 启动预览.sh 只是本地用的，上线时可以删掉，不影响页面。

注意：每改完 data.json 存盘，刷新页面就能看到最新内容（预览服务默认关缓存）。
